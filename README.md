## 👋 Tentang Saya

Halo, saya **Imam**, mahasiswa Informatika Universitas Madura sekaligus **developer aplikasi web dan mobile**. Saya membangun produk digital utuh: dari rancangan database dan API di sisi backend, antarmuka yang bersih dan responsif, sampai aplikasi berjalan dan dipakai langsung oleh pengguna.

Saya percaya software yang baik itu **sederhana, mudah dirawat, dan menyelesaikan masalah nyata**. Karena itu proyek saya berangkat dari kebutuhan lapangan: absensi, akademik, keuangan organisasi, hingga otomasi perangkat IoT.
